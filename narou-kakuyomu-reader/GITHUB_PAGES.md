# GitHub Pages への公開 & USB・ファイル移行ガイド

本プロジェクトは **完全静的Webアプリケーション（PWA）** として設計されており、自宅サーバーやトンネルを一切使わずに **GitHub Pages（完全無料・永続稼働）** に公開して任意の端末から利用できます。

---

## 1. GitHub Pages への公開手順（ネットへ放流）

### ステップ 1: GitHubでリポジトリを作成
1. GitHub（https://github.com/）にログインし、新しいリポジトリを作成します（例: `narou-reader`）。
2. Public（公開）を選択します。

### ステップ 2: ファイルをアップロード
本フォルダ（`narou-kakuyomu-reader`）内のファイルをそのままリポジトリにプッシュ（またはWeb画面からドラッグ＆ドロップでアップロード）します：
- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `css/`
- `js/`
- `icons/`
- `README.md`
- `export_tool.py`（※PC用ツール）
- `worker.js`（※任意: 自分専用プロキシ用）

### ステップ 3: GitHub Pagesを有効化
1. リポジトリの **「Settings」**（設定）タブを開きます。
2. 左メニューの **「Pages」** をクリックします。
3. **「Build and deployment」** の Source を **「Deploy from a branch」** にし、Branch を **`main`（または `master`）** / **`/ (root)`** に設定して **「Save」** を押します。
4. 数十秒待つと、上部に公開URLが表示されます：
   ```text
   https://<あなたのユーザー名>.github.io/<リポジトリ名>/
   ```
5. このURLをPCやスマホ（Pixel 9a等）のブラウザで開けば、いつでもどこでも起動できます！
   - Chromeのメニューから **「ホーム画面に追加」** または **「アプリをインストール」** を押せば、全画面・アドレスバーなしのネイティブアプリとしてインストールされます。

## 2. USB / ファイルを使った簡単な作品移行（バックアップ＆復元）

自宅サーバーやWi-Fi同期を使わず、**USBメモリやGoogle Drive経由で一瞬で作品・本文を移行**できます。

### 方法 A: アプリ画面からバックアップ（一番簡単）
1. **PC側のブラウザでアプリを開く**（またはダウンロード済み端末）
2. 本棚の上部にある **「💾 バックアップ保存」** ボタンをクリック
   - `narou_reader_backup_YYYYMMDD_HHMM.json` がPCに保存されます。
3. **そのJSONファイルをUSBメモリ等でスマホに移動**
4. **スマホ側のアプリを開く**
5. 本棚の上部にある **「📂 バックアップ復元」** ボタンをタップし、移動したJSONファイルを選択
6. **一瞬で本棚と全話本文がスマホのオフライン領域（IndexedDB）に完全復元されます！**

---

### 方法 B: PCツールで一括ダウンロードして直接USB用ファイルを作る (`export_tool.py`)
PCのPythonから直接高速に作品を取得し、最初からUSB移行用JSONを出力することもできます：

```bash
# なろうの作品を全話ダウンロードしてJSONを生成
python export_tool.py n2267be

# カクヨムの作品をダウンロードしてJSONを生成
python export_tool.py https://kakuyomu.jp/works/1177354054880238351
```
出力された `backup_作品名_ncode.json` をスマホに移し、アプリの「📂 バックアップ復元」で読み込むだけで完了です！

## 3. スマホ単体で直接作品を追加・ダウンロードしたい場合（任意）

スマホのGitHub Pages版アプリから直接「なろう」「カクヨム」を検索・追加したい場合は、ブラウザのCORS制限を回避するためのプロキシを設定できます。

1. **Cloudflare Worker（完全無料）を作成**:
   - `worker.js` の内容を Cloudflare Worker にコピペしてデプロイ（1分で完了）。
2. **アプリに登録**:
   - アプリ右上の **「⚙️ 設定」** をタップ。
   - 発行されたWorkerのURL（例: `https://my-proxy.xxxx.workers.dev/?url=`）を入力して「保存」。
3. これで、外部プロキシの停止に影響されない、自分専用の高速ダウンロード環境が永続的に機能します。
