# 「なろう」カクヨム風オフラインリーダー (PWA)

「小説家になろう」の作品を、カクヨムアプリのような操作感（最下部到達後の引き上げ・スワイプによる次話移動、触覚フィードバック）で閲覧でき、事前にダウンロードしてオフライン（機内モード等）でも快適に読めるAndroid 16（Pixel 9a）最適化リーダーです。

---

## 📱 Pixel 9a（Android 16）での開き方・インストール手順

1. **PC側でサーバーが起動していることを確認**:
   - `python server.py` を実行（現在バックグラウンドで起動中）。
   - PCとPixel 9aが**同じWi-Fiネットワーク**に接続されている必要があります。
2. **スマホのChromeでアクセス**:
   - Pixel 9aのChromeを開き、以下のアドレスを入力:
     ```text
     http://192.168.0.111:8000
     ```
     （※PCのローカルIPが `192.168.0.111` の場合）
3. **PWAとしてアプリ化（ホーム画面に追加）**:
   - Chrome右上のメニュー（縦3点アイコン `︙`）をタップ
   - **「ホーム画面に追加」** または **「アプリをインストール」** をタップ
   - これにより、ネイティブアプリのように全画面・アドレスバーなしで起動できるようになります。

## ✨ 主な実装済み機能

### 1. カクヨム風リーダー（コアUI/UX）
- **ダークモード / 漆黒モードの鮮明化**:
  - ダークモード（`#16171a`）および漆黒モード（`#000000`）の文字色を純白（`#ffffff`）に改善。くっきりと高いコントラストで夜間読書も快適。
- **カクヨム準拠のワンタップHUDメニュー**:
  - 指の接触ブレや短距離スクロール（35px以内）を許容し、画面タップで確実に操作メニューを開閉。
  - **エピソードシークバー（スライダー）**: 指でつまんで好きな話数へ瞬時にジャンプ。
  - **ボトムアクションバー**: 「目次」「縦書き/横書き切り替え」「文字・背景設定」をワンタップ操作。
- **最下部スクロールでの「引っ張って次話へ」（Pull to Next Chapter）**:
  - 本文最下部に到達後、さらに上に引き上げるとバネのような抵抗感でコンテンツが持ち上がり、円形プログレスリングが表示されます。
  - しきい値（75px）に達すると「離して次の話へ！」に変化し、**端末バイブレーション（触覚フィードバック）** が作動。
  - 指を離すとスムーズなスライドアニメーションとともに次話へ移動します。
- **最上部スクロールでの「引き下げて前話へ」**:
  - 第2話以降、一番上から引き下げると前話へ直感的に戻れます。
- **読書位置の自動記憶**:
  - スクロール位置と進行度（%）をミリ単位でIndexedDBに自動保存。「続きから読む」で瞬時に復元。

### 2. オフライン対応 & バックグラウンドダウンロード管理
- **読書を止めないバックグラウンド一括ダウンロード**:
  - 一括ダウンロードを開始しても画面を占有せず、フローティング進捗バーで状況を確認しながら**そのままリーダーで読書を続行可能**！
  - 次の話へ進んだ際、バックグラウンドDLにより既に保存されていれば即座にオフラインDBから読み込まれます。
- **完全ローカル保存（IndexedDB）**:
  - 作品情報、各話本文、サブタイトル、前書き、後書きを端末内に安全に格納。
  - 電波のない環境（機内モード・地下鉄等）でも100%閲覧可能。
- **オフライン体験用サンプル作品内蔵**:
  - 初回起動時から『【サンプル】異世界でオフラインリーダーを作ったら無双した件』（全3話）が本棚に入っており、ネット環境がなくてもすぐにカクヨム風の引っ張り次話移動を体験可能。

### 3. 軽量サーバー & CORSプロキシ (`server.py`)
- Python 3 標準ライブラリのみで動作（外部パッケージ不要）。
- なろう公式APIおよびHTMLスクレイピングを中継し、ブラウザのCORS制限を完全回避。
- マルチスレッド対応（`ThreadingHTTPServer`）で高速なアセット配信と並行ダウンロードに対応。
